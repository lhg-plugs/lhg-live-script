# lhg-ls-compliance：话术合规与结构自查

> 目标：脚本交付前最后一道门——违禁词零容忍（封号风险），结构缺件必 warning。
> 核心纪律：**blocker 不清零，不许交付；warning 要么修，要么写豁免理由。**

## 1. 何时使用

- 开播脚本写完 → 跑一遍本节清单 + `live_audit.py`
- 主播即兴加词 → 对第 2 节词库快速过一遍
- 交付前硬门 hook 拦截 → 按第 5 节修

## 2. 违禁词五类清单（命中即 blocker）

### ① 极限词（广告法红线）

`最、第一、首个、唯一、顶级、顶尖、国家级、全球首发、史无前例、绝无仅有、万能、100%、零风险`

注意"最"的语境：✅"最后 50 单"（时间/数量词，不违规）；❌"最好用的面霜"（极限词，违规）。

改写：❌"全网最好的面霜" → ✅"我空瓶 3 罐的面霜"（用证据代替极限词）

### ② 虚假承诺

`包治、根治、稳赚、躺赚、一夜暴富、稳赚不赔、保证赚钱、百分百有效、无效退款、假一赔十`

改写：❌"用了保证有效" → ✅"不适合 7 天无理由退"（承诺 → 售后保障）

### ③ 功效宣称（美妆/食品重灾区）

`祛痘、美白、减肥、降压、降糖、治疗、治愈、抗癌、增高、丰胸、生发、祛斑、淡斑、排毒`

改写：❌"这款能美白" → ✅"坚持用，肤色提亮看得见"（功效 → 体验描述）

### ④ 价格欺诈

`全网最低价、史低、比官网还便宜、亏本卖、赔钱卖`

改写：❌"全网最低价" → ✅"专柜 299，今天 59 块 9"（比价 → 锚点对比）

### ⑤ 封建迷信

`开光、转运、招财、辟邪、改命、旺夫、镇宅`

改写：❌"戴上转运" → ✅"戴上好看"（迷信 → 审美）

## 3. 结构完整性检查清单

| 检查项 | 规则 ID | 缺失后果 |
|---|---|---|
| 开场留人钩子段 | ST-HOOK-001 | 进来就走，留存崩 |
| 转粉福利点 | ST-FOLLOW-001 | 流量沉淀不下来 |
| 逼单倒计时 | ST-CLOSE-001 | 无紧迫感，转化打折 |
| 价格锚点对比 | ST-CLOSE-002 | 观众感知不到便宜 |
| 下单引导（小黄车/链接） | ST-CTA-001 | 观众不知道在哪买 |

任一缺失 → warning；逼单环节同时缺倒计时和锚点 → 两条 warning，必须补。

## 4. 口语化与节奏检查

- 书面语（进行/予以/综上所述）→ 换口语（Q-TONE-001）
- 单句超 30 字 → 拆短句（Q-LONG-001）
- 全场无互动指令（扣 1/投票/点名）→ 加（Q-RHYTHM-001）
- 无时间轴标记 → 加（Q-TIME-001）

## 5. 确定性脚本使用

```bash
python3 scripts/audit/live_audit.py --target ./delivery/ --format text
python3 scripts/audit/live_audit.py --target ./delivery/ --format json --fail-on blocker
```

- exit 0：无 blocker（可交付；warning 建议修）
- exit 2：有 blocker（违禁词命中，必须改）
- `--fail-on warning`：严格模式，warning 也算失败（适合大促前）

## 6. 交付前硬门

本插件带一个交付前检查 hook：当 Bash 命令包含"交付/发布"意图且目标是直播脚本时，自动跑合规审计；命中 blocker 直接拦截交付。

逃生方式（按推荐度排序）：

1. 修好违禁词后重新交付（推荐）
2. 紧急情况：`LHG_LS_HOOKS_OFF=1 <交付命令>`（单次豁免本次 hook）
3. `/plugin disable lhg-live-script`（整个插件停用，hooks 不再触发）

设计原则：hook 脚本内部出错时 fail-open 直接放行，不因插件自身故障骚扰用户；真正的门禁在 `/lhg-live-script:live-audit`。

## 7. 反模式

- ❌ "就一句极限词，应该没事"——平台是机器审核，不讲"应该"
- ❌ 违禁词用拼音/谐音绕过——"最"写成"醉"同样违规，且显得low
- ❌ warning 全忽略直接交付——warning 攒多了就是转化率杀手
- ❌ 为清零改规则/删词库——作弊，不许

## 8. 自检与反馈

每次执行完本 skill，做一次轻量自检：

1. `live_audit.py` 跑了吗？→ 没跑等于没自查
2. blocker 清零了吗？→ 没清零不许交付
3. warning 修了还是豁免了？→ 要有记录，不能"假装没看见"
4. 词库要补充吗？→ 发现新违禁词，先加词库再交付

标准冒烟用例：用 fixtures/bad（含极限词+缺倒计时）跑审计，确认 5 类违禁词规则与 ST-CLOSE-001 全部命中；用 fixtures/good 跑，确认零 blocker。

反馈渠道：以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-live-script/issues，正文写清"输入 → 错误输出 → 期望输出"。发现新违禁词请附原文截图描述。

## 10. 违禁词改写 10 例（背下来）

1. ❌"最好用的面霜" → ✅"我空瓶 3 罐的面霜"
2. ❌"全网最低价" → ✅"专柜 299，今天 59 块 9"
3. ❌"美白效果显著" → ✅"坚持用，肤色提亮看得见"
4. ❌"第一品牌" → ✅"卖了 10 万单的老品牌"
5. ❌"包治痘痘" → ✅"痘肌姐妹可以试试，不合适 7 天退"
6. ❌"减肥神器" → ✅"0 蔗糖，配料表干净"
7. ❌"史无前例的优惠" → ✅"今年最大的一次力度"
8. ❌"100%正品" → ✅"支持专柜验货，假一赔十写进详情"
9. ❌"转运手链" → ✅"编织手链，戴上好看"
10. ❌"无效退款" → ✅"7 天无理由，拆开用了也能退"

改写心法：**极限词→证据，承诺→售后，功效→体验**。记住这 9 个字，临场也能改。

## 11. 常见问题 FAQ

**Q：说了极限词，真的会被罚吗？**
A：平台是机器+人工双审，"最""第一"类是关键词直命中。一次警告限流，多次封号——别赌。

**Q：谐音/拼音绕过违禁词行不行？**
A：不行。审核模型吃过这一套，"醉好用"照样命中，且被观众截图就是公关事故。

**Q：warning 可以忽略吗？**
A：可以，但要有记录（豁免理由）。warning 攒多了=转化率慢性失血，大促前建议开 `--fail-on warning`。

**Q：主播临场即兴加了词，怎么快速检查？**
A：过五类清单：极限/承诺/功效/价格/迷信，5 秒过一遍。拿不准的，换成第 10 节的安全替代。

**Q：不同平台规则一样吗？**
A：大框架一样（广告法是底线），细节有差（某平台对"最低价"更严）。词库是按最严口径整理的，过了这套，各平台基本安全。
