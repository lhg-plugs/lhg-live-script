# /lhg-live-script:live-hook —— 开播钩子

用户输入在 `$ARGUMENTS` 中：`[品类] [产品/主题]`。

全程加载 `lhg-ls-hook` 指导，可分派给 `hook-writer` agent。

## 流程

### 1. 定品类
- 品类决定钩子类型优先级（美妆→痛点式，食品→福利式，服饰→身份式，见 lhg-ls-hook 第 6 节）。

### 2. 写 3 条钩子
- 从 4 类（福利/悬念/痛点/身份）里挑 3 类各写 1 条。
- 每条 ≤3 秒可念完，好处前置，删掉"欢迎/大家/今天"无效词。

### 3. 三问质检
- 每条过钩子三问：3 秒念完？删掉它开播还成立？承诺能兑现？
- 不过的重写，不许将就。

### 4. 用户拍板
- 3 条摆给用户选，**用户拍板用哪条再结束**。可混搭（A 的福利 + B 的悬念）。
- 交付时附 30 秒衔接话术（钩子→第一个福利点）。

## 硬规则
- 只给 1 条钩子 → 不许（必须 3 条让用户选）。
- 钩子超 3 秒 → 打回重写。
- 承诺的福利没和运营确认 → 标注"待确认"，不许当已确认写。
