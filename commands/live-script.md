# /lhg-live-script:live-script —— 完整开播脚本

用户输入在 `$ARGUMENTS` 中：`[品类] [产品列表] [--minutes 分钟数]`。时长缺省 120 分钟。

全程加载 `lhg-ls-structure` 指导骨架，钩子部分用 `lhg-ls-hook`，逼单用 `lhg-ls-close`，最后用 `lhg-ls-compliance` 自查。话术撰写可分派给 `hook-writer` / `closer` agent。

## 流程

### 1. 定品类与产品
- 品类（三选一：美妆/食品/服饰，其他品类按最接近的套）：决定钩子类型、讲解重点、合规红线（见 lhg-ls-structure 第 4 节对照表）。
- 产品列表：每款标出原价/直播价/是福利款还是利润款。价格不全 → 问用户要，不许编价格。
- 福利款和利润款没分清 → 帮用户分：引流不赚钱的是福利款。

### 2. 搭五段式骨架
- 按 lhg-ls-structure 第 2 节时长配比排时间轴（开播留人/转粉福利/产品讲解/逼单穿插/收尾预告）。
- 排品顺序：福利款开场 → 利润款中段 → 福利款返场 → 利润款收尾。
- 骨架先给用户确认：**骨架没拍板，不许写逐字稿**。

### 3. 写开场钩子
- 按 lhg-ls-hook 第 3 节四公式写 3 条钩子，摆给用户选。
- 用户拍板后，钩子写入骨架开场段，并安排每 2 分钟循环话术。

### 4. 写逐段话术
- 转粉福利段：按三要素（门槛低/即时性/高频次）写福利点话术。
- 产品讲解段：每款按"讲人群→讲差异→讲证据"三讲结构写。
- 逼单：每款利润款写 3 次逼单（讲完/5 分钟后/返场），福利款 1 次；逼单三件套必须齐（见 lhg-ls-close）。
- 段间衔接：用 lhg-ls-structure 第 5 节衔接话术库，不许硬切。
- 全稿口语化：短句、一句话一个意思，写完读出声。

### 5. 合规审计
- 跑 `python3 scripts/audit/live_audit.py --target ./delivery/ --format text`。
- blocker（违禁词）必须清零；warning 修或写豁免理由。
- 审计不过 → 打回第 4 步改，不许交付。

### 6. 交付
- 输出：时间轴总表 + 逐段话术稿 + 逼单话术卡（单独一页，主播手持）+ 审计报告。
- 提醒用户：开播前和运营 double check 福利/价格可兑现。

## 硬规则
- 价格/福利没确认就写逼单 → 不许（编价格=价格欺诈）。
- 骨架没让用户确认就写逐字稿 → 不许。
- 违禁词 blocker 没清零就交付 → 不许。
- 逼单缺倒计时 → warning，必须补或写豁免理由。
